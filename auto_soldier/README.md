# Auto Soldier（Godot 4.7 / 2D）

兵士が360度動けるマップを自動で移動しながら、押し寄せる敵と自動で戦うゲーム。
プレイヤーが操作するのは、レベルアップ時の強化を3択から選ぶことだけ。

## 遊び方

1. Godot 4.7 で `auto_soldier/project.godot` を開く
2. F5（または右上の再生ボタン）で実行
3. レベルアップしたら強化を **クリック** か **1〜3キー** で選ぶ
4. ゲームオーバー後は **R キー** かボタンでリトライ

## ゲームの仕組み

| 要素 | 内容 |
| --- | --- |
| 射撃（点） | 一番近い敵を自動で撃つ。射程が長く単体向け |
| 剣（面） | 近づいた敵を扇形にまとめて斬る。敵の弾もかき消す |
| 自動移動 | 敵から適度な距離をとり、囲まれたら敵の薄い方向へ脱出、弾をよける |
| 経験値 | 敵を倒すと獲得。貯まるとレベルアップして強化3択 |

### 敵

- **赤（grunt）**：まっすぐ近づいてくる基本の敵
- **紫ひし形（archer）**：距離をとって弾を撃ってくる遠距離型（20秒〜）
- **オレンジ（runner）**：小さくて速い（40秒〜）
- **大きい暗赤（brute）**：硬くて重い。経験値が多い（80秒〜）
- 60秒から約50秒ごとに、周囲を囲む包囲ウェーブが来る

### 強化一覧（`scripts/upgrades.gd`）

射撃数+1 / 速射 / 強化弾 / 貫通弾 / 剣術 / 大振り / 回転斬り（360度） /
突進突き（数秒ごとに敵へ突進） / ペットの仲間（自動射撃） / 頑丈 / 再生 / 俊足

新しい強化を追加するときは `upgrades.gd` の `LIST` に1行追加し、`apply()` に効果を書く。

## ファイル構成

```
auto_soldier/
├── project.godot
├── scenes/main.tscn        … ルートのシーン（中身はすべてスクリプトで生成）
└── scripts/
    ├── main.gd             … マップ・敵の出現・経験値/レベル管理
    ├── soldier.gd          … 兵士（自動移動AI・射撃・剣・突進）
    ├── enemy.gd            … 敵（近接型・遠距離型）
    ├── bullet.gd           … 弾（味方/敵共通）
    ├── pet.gd              … ペット
    ├── upgrades.gd         … 強化の定義と効果
    ├── level_up_ui.gd      … 強化3択画面
    ├── hud.gd              … HP・経験値・時間などの表示とゲームオーバー画面
    └── slash_effect.gd / damage_text.gd / burst_effect.gd … 演出
```

画像素材は使っておらず、キャラクターはすべて `_draw()` で図形として描いている。
あとからスプライト画像に差し替えたい場合は、各スクリプトの `_draw()` を置き換えればよい。

## 調整しやすい値

- 難易度：`main.gd` の `_update_spawning()`（出現ペース）、`_spawn_enemy()` の HP 倍率
- 必要経験値：`main.gd` の `xp_to_next = 4 + level * 3`
- 兵士の初期ステータス：`soldier.gd` の先頭の変数
- 敵のステータス：`enemy.gd` の `setup()`
