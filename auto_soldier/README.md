# Auto Soldier（Godot 4.7 / 2D）

フィールドの一番下にある城を、自動で戦う部隊（遊撃・迎撃・狙撃・近衛・重装・築城・工兵・修理）と城の迎撃システムで守るゲーム。
プレイヤーが操作するのは、レベルアップ時の強化を3択から選ぶことだけ。

## 遊び方

1. Godot 4.7 で `auto_soldier/project.godot` を開く
2. F5（または右上の再生ボタン）で実行
3. レベルアップしたら強化を **クリック** か **1〜3キー** で選ぶ
   - 3つ目の選択肢の下にある **「リロール」ボタン**（または **R キー**）で、出ている3つの候補を1回だけ引き直せる（なるべく別の候補が出る。特別強化の画面なら特別強化から引き直す）
4. 城のHPが0になるとゲームオーバー。**R キー** かボタンでリトライ（ゲームオーバー画面から部隊戦績・強化状態も見られる。**「戦績まとめ」** では、部隊・設備の種類ごとの与ダメージ合計、強化と特別強化を取った数、敗北時のレベルが一覧で見られる）
5. 城のHPバーの下にある **「部隊戦績」ボタン**（または **Tab キー**）で、各部隊の個体ごとの与ダメージ・撃破数・被ダメージを確認できる（開いているあいだは一時停止）
6. その下の **「オート選択」ボタン**（または **A キー**）で有効にすると、レベルアップの強化をランダムで自動的に選ぶ（ゲームは止まらない）
7. その下の **「強化状態」ボタン**（または **U キー**）で、取った強化の一覧を確認できる。項目をクリックすると詳しい内容が見られる（開いているあいだは一時停止）
8. 画面右下の **「速度」ボタン**（または **F キー**）で、通常速度 ⇔ 2倍速 を切り替えられる

## ルール

- 城のHPは毎秒1だけ自然に回復する。もっと回復させるには **修理部隊** が必要（修理玉がためる「回復した量」には自然回復も入る）
- 敵は上や左右から現れて、城を目指して進んでくる
  - 敵が城に触れると、その敵は消えて城がダメージを受ける（経験値は入らない）
  - 敵の弾が城に当たっても城がダメージを受ける
- **遊撃部隊**（最初は2人）：フィールドを動き回って敵を倒しに行く
  - 常に自分から一番近い敵を狙って攻撃しに行く
  - 射撃（点）で遠くの敵を、剣（面）で近くの敵をまとめて倒す
  - 倒されても10秒後に城から復活する
- **迎撃部隊**（強化で加入、最大3人）：盾＋槍で城の近くを守る
  - 盾を向けている前方の狭い範囲からの攻撃は完全に無効
  - 槍はリーチが長いが横幅は狭い（直線上の敵をまとめて貫く）
  - 足が速い（元の2倍）。近くに敵がいない待機中は、城へ飛んでくる敵の弾の通り道に立って、盾で正面から受け止める
- **近衛部隊**（強化で加入、最大3人）：フィールドの一番下にいる敵（城に一番近い高さの敵）を最優先で狙う
  - 敵の近くまで行ったら、一直線に高速で突進して、通り道の敵をまとめて貫く（突進中は無敵）
  - 突進は隠密兵を1発で倒せる威力（敵が強くなるのに合わせて威力も上がる）
- **修理部隊**（強化で加入、最大3人）：城のまわりを歩きながら修理して、1人につき城のHPを毎秒3回復する（敵からは狙われない）
- **狙撃部隊**（強化で加入、最大3人）：迎撃部隊の後ろ（城の屋根の上あたり）に立ち、弓で遠くを狙い撃つ（矢はとても速く、最初から敵を2体貫通する）
  - 一番近い遠距離型の敵（弓兵・迫撃砲）を優先して狙う。いなければ一番近い敵
  - 敵からは狙われない
- **重装部隊**（強化で加入、最大1体）：足は遅いが耐久力と攻撃力が高い
  - マップ内を自由に歩き回り、マップの真ん中に一番近い敵を最優先で倒しに行く（敵がいないときはマップの真ん中で待つ）
  - 攻撃は遊撃部隊と同じ扇形の斬撃のみ（範囲・威力は遊撃部隊より大きい）
- **工兵部隊**（強化で加入、最大3人）：ランダムな地点へ移動し、6秒かけて罠を仕掛ける。爆弾と落とし穴を交互に仕掛け続ける
  - 爆弾：近くに敵が来たら1秒後に爆発して範囲ダメージ（200）
  - 落とし穴：近くに敵が来たら1秒後に作動して範囲ダメージ（100）＋範囲内の敵が10秒間動けなくなる
  - 罠はフィールド全体で最大20個。敵からは狙われない
- **築城部隊**（強化で加入、最大3人）：城の上側180度を囲むように、20秒ごとに壁を1枚（約12度）建てる
  - 15枚建てば半円が完成。壊れた場所には建て直しに行く
  - 壁1枚の耐久は10。敵の弾は1発で耐久1、敵が体当たりすると耐久5削れる（ダメージの大きさには関係なし）。ぶつかった敵はHPが半分になり（築城部隊の与ダメに入る）、上側へ大きく弾き飛ばされて5秒気絶する（自爆兵だけはその場で爆発して消える）
- **ノックバックのクールタイム**：どんな攻撃でも、同じ敵が押されるのは1秒に1回だけ（`enemy.gd` の `KB_COOLDOWN`）。押されたあと1秒は、ほかの攻撃が当たっても押されない（壁にぶつかったときの弾かれは別）
- 射撃（弾・矢・火矢など）でも敵は少し押し戻される（下側の城の方へは押されない）。爆発・斬撃・突進・転がる物などでは大きく吹き飛ぶ
- どんな攻撃のノックバックでも、敵が城に近づく向きには押されない（城へ向かう分の力は消えて、横や奥へだけ押される）
- 動かない敵（砲台要塞・迫撃砲・誘導砲兵）は、どんな攻撃でもノックバックしない
- 敵を倒すと経験値が入り（獲得量は1.3倍：`main.gd` の `XP_GAIN`）、レベルアップで強化を3択から1つ選べる

### 敵
- 敵のHPは時間とともに上がり続ける（ボス以外も。上限なし）

- **赤（grunt）**：まっすぐ城へ向かう基本の敵
- **紫ひし形（archer）**：離れた所から城や兵士を撃ってくる（25秒〜）
- **オレンジ（runner）**：小さくて速い（45秒〜）
- **大きい暗赤（brute）**：硬くて重い。城に触れると大ダメージ（80秒〜）
- **青緑のとがった敵（hunter／刺客）**：城は無視して兵士（遊撃・迎撃）だけを狙う。壁もすり抜ける（75秒〜）
- **黄緑の塊（splitter／分裂体）**：倒すと小さな分裂体3体に分かれる（60秒〜）
- **ピンクの十字（healer／治癒師）**：後方にとどまり、3秒ごとに周りの敵を回復する（100秒〜）
- **黒っぽい赤（bomber／自爆兵）**：足が速い。兵士・壁・城にぶつかると爆発（壁の耐久を15削る）（120秒〜）
- **半透明の灰色（stealth／隠密兵）**：画面の右下・左下の隅から現れて城を狙う。壁のない横から攻めてくる。HPは低め（90秒〜）
- **砲身つきの土台（mortar／迫撃砲）**：マップの端（上端・左右）に陣取って動かず、壁を飛び越える山なりの砲弾で城を撃ってくる。着弾地点には赤い印が出る（180秒〜、同時に出る数に上限あり）
- **赤いトゲトゲの玉（ringer／弾幕兵）**：5秒ごとに全方位へ赤い弾を10発撃ちながら、城へ向かってくる（150秒〜）
- **ミサイル発射台（seeker／誘導砲兵）**：マップの端に陣取って動かず、遊撃・近衛・重装のキャラクターへ（迎撃と、見張り櫓・かかしなどの設置物は狙わない）、しつこく曲がって追いかけてくる誘導弾を2〜3秒ごとに撃つ（200秒〜、同時に出る数に上限あり）
- 50秒ごとに横一列の大群が来る
- Lv5・15・25…になると、迫撃砲部隊（迫撃砲8体）がマップの端に一気に現れる
- 画面右上に、いま侵攻中の敵の数が出る

### ボス（Lv10ごと）

Lv10・20・30…になると、画面上からボスが現れる（画面上部にHPバーと名前が出る）。3種類のボスが順番に来る（破城の魔王 → 砲台要塞 → 分裂の魔獣 → 破城の魔王…）。

**破城の魔王**（Lv10・40・70…）
- 5秒ごとに全方位へ弾を撃ち、12秒ごとに手下を5体呼ぶ
- 壁に触れると壁の耐久を7減らし、ボス自身はダメージを受けずに、ランダムな方向（下側の城の方は除く）へ大きく弾かれる。気絶はしない（消えずに何度もぶつかってくる）
- 城に着くと、消えずに2秒ごとに大ダメージを与え続ける

**砲台要塞**（Lv20・50・80…）
- 画面上部に陣取って動かない（ノックバックも効かない）。HPは破城の魔王より低い。そのかわりいろんな弾幕を順番に撃ってくる
  （うずまき弾 → 兵士を狙う扇状の弾 → 全方位リング → 城の方への乱れ撃ち）
- 9秒ごとに、城を狙った山なりの砲弾3発と、まっすぐ飛ぶ大砲弾を撃つ
- 弾幕は兵士向けなので、城に当たったときのダメージは2割

**分裂の魔獣**（Lv30・60・90…）
- 緑のスライムのボス。全方位へ弾を撃ちながら城へ進んでくる（最初の体の基本HPは294。ボスの中で一番低め）
- 倒されると2体に分裂し、それも倒されるとさらに2体に…と最大4回分裂する（最後は16体）
- 分裂するたびにHPは半分、体は小さく、足は速く、弾は少なく弱くなる
- HPバーには、分かれた体ぜんぶのHPの合計と、残りの体の数が出る。全部倒すと撃破

破城の魔王・分裂の魔獣は攻撃で少し押される（ふつうの敵の4割くらい・下側の城の方へは押されない）。砲台要塞はノックバックが効かない。どのボスも気絶はほとんど効かない（氷結の結界や居座り岩などで足が遅くなるのは効く）。治癒師の回復もほとんど効かない。出るたびに強くなる。倒すと経験値が多い。

部隊の強化はその部隊の全員に効く（あとから増員された兵士にも反映される）。
迎撃・築城の強化は、その部隊が加わってから候補に出るようになる。
新しい強化を追加するときは `upgrades.gd` の `LIST` に1行追加し、`apply()` に効果を書く。

画像素材は使っておらず、すべて `_draw()` で図形として描いている。
あとからスプライト画像に差し替えたい場合は、各スクリプトの `_draw()` を置き換えればよい。

## 調整しやすい値

- 難易度：`main.gd` の `_update_spawning()`（出現ペース）、`_hp_mult()`（敵のHP倍率：t = 秒×1.3 として `1 + t/75 + (t/170)²`。5分で約×11.5、10分で約×32.5）
- 必要経験値：`main.gd` の `xp_needed()`
- 城のHP：`castle.gd` の `max_hp`
- 遊撃部隊の初期ステータス：`soldier_stats.gd`
- 迎撃部隊の初期ステータス：`guard_stats.gd`
- 壁の建築時間・防げる回数・幅：`walls.gd` の `build_time` / `wall_max_hp` / `wall_width`
- 最初の兵士数：`main.gd` の `_ready()` で `add_soldier()` を呼んでいる回数
- 敵のステータス：`enemy.gd` の `setup()`
