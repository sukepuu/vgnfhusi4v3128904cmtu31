# Auto Soldier（Godot 4.7 / 2D）

バージョン：**2.3**（`project.godot` の `config/version`）。Windows用に出力するたびに0.1ずつ上がる（1.0 → 1.1 → 1.2 …）。ウインドウの名前は「Auto Soldier ver2.3」のようにバージョン付きで出る（同時に立ち上げた2つ目からは「Auto Soldier ver2.3 [2]」のようにセーブの枠の番号も付く）。**「更新内容」ボタン**（デバッグ設定の下。ほかのデバッグ用ボタンと一緒に、ふだんは隠れていて M キーで出る）で、バージョンごとの更新内容を新しい順に見られる（`changelog_ui.gd` の `CHANGES`。出力のたびに新しいバージョンの内容を先頭に足す）。デバッグ用ボタンは、もう一度 M キーを押すとまた隠れる

フィールドの一番下にある城を、自動で戦う部隊（遊撃・迎撃・狙撃・近衛・重装・築城・工兵・修理）と城の迎撃システムで守るゲーム。
プレイヤーが操作するのは、レベルアップ時の強化を3択から選ぶことだけ。

## 遊び方

1. Godot 4.7 で `auto_soldier/project.godot` を開く
2. F5（または右上の再生ボタン）で実行
3. ゲームが始まる
4. レベルアップしたら強化を **クリック** か **1〜3キー** で選ぶ
   - 3つ目の選択肢の下にある **「リロール」ボタン**（または **R キー**）で、出ている3つの候補を1回だけ引き直せる（なるべく別の候補が出る。特別強化の画面なら特別強化から引き直す）
4. 城のHPが0になるとゲームオーバー。**R キー** かボタンでリトライ（ゲームオーバー画面から部隊戦績・強化状態も見られる。ボタンは「強化状態を見る」→「被害結果確認」→「戦績まとめ」の順。**「戦績まとめ」** では、部隊・設備の種類ごとの配置数（現在数/上限）・与ダメージ合計・強化と特別強化を取った数、敗北時のレベルが一覧で見られ、城の兵装も配置数に含まれる。強化も特別強化も取っていない種類は表示されない）
   - 「もう一度」（R キー）でやり直したときは、オート選択の有効中・無効中がそのまま残る（有効中だったら有効中のまま始まる）
   - **オートセーブ**：レベルが上がるたびに、そのときのゲームの状態をまるごと自動で保存する（`user://autosave_<枠>_lv<レベル>.dat`。直近11レベル分を保持し、それより古いものは自動削除。ゲームを閉じても残る）。レベルアップの3択が出たあと、そのフレームの最後に保存する（`autosave.gd`）
   - **セーブの枠**：ゲームを何個も同時に立ち上げても、オートセーブはお互いに上書きしあわない。立ち上げたゲームごとに、空いている一番小さい番号の枠（1, 2, 3…）を使い、その枠のセーブ群を使う。「前回のLvからリスタート」は最新のセーブから読む（`save_slot.gd`）
     - 枠2からは、ウインドウの名前の最後に「 [2]」のように枠の番号が付く（枠1のときは付かない）
     - 枠を取ると `user://slots/slot_<枠>/` というフォルダを作り、その中の `alive.txt` に数秒ごと（一時停止中も）「プロセス番号と時刻」を書く。フォルダを作れたゲームだけがその枠を取れるので、同時に立ち上げても同じ枠にはならない
     - ゲームを閉じると枠は空く（セーブのファイルは残る）。なので、1つだけ立ち上げ直すとまた枠1になり、前に枠1で遊んだセーブから続けられる。強制終了などで枠のフォルダが残っても、`alive.txt` が15秒より古ければ空いている枠として使う
     - 前の1つだけのオートセーブ（`user://autosave.dat`）は、枠1のセーブとして引き継ぐ
   - ゲームオーバー画面の「もう一度」の下にある **「前回のLvからリスタート（Lv○・mm:ss）」ボタン** で、最後にオートセーブしたところから続きを遊べる（オートセーブがあるときだけ出る）。さらにその下に **「○Lv前から再開」ボタン** が出る（保持している一番古いセーブから再開。直近11レベル分のうち最古のもの）。保存したときに3択が出ていたら、同じ3択がもう一度出る（引き直しにはならない。リロールも保存したときの状態のまま）。オート選択の有効中・無効中は、押す前の状態がそのまま残る（有効中ならその3択からオートで選ぶ）。続きを遊んでレベルが上がると、またオートセーブされる
   - 保存されるもの：経過時間・レベル・経験値・撃破数・取った強化と、強化で変わったステータス全部、城（HP・兵装・特別強化・待ち時間）・壁、全部の部隊の兵士（位置・HP・復活待ち・攻撃や突進の待ち時間）、ペット（突進の途中も）・合体ペット・城ロボ、設置物・罠・採掘場・もぐら・炎などのダメージ地帯、すべての敵とボス（位置・HP・攻撃パターン・分裂の魔獣の分かれ具合・大司教など）、敵の出現の予定（大群・鉄甲兵・大司教・ボスのHPの基準）、部隊戦績・被害状況（直近30秒も）
   - 保存されないもの：飛んでいる弾・砲弾・投げた物（ブーメラン・鉄球など）・少し遅れて起きる爆発・見た目だけの演出。ロードするとそれらは消えている。乱数の続きも保存しないので、ロードしたあとの敵の出方などは保存したときと同じにはならない
   - スクリプトの変数を名前で1つずつ書くのではなく、ノードの変数を全部まとめて書き出しているので、あとで部隊・敵・変数を足しても、たいていはそのまま保存される。新しく弾や演出のスクリプトを作ったときは、`autosave.gd` の `SKIP_SCRIPTS` に足す（足さないと、それも保存される）
   - 保存するときは、辞書をかならず `keys()` / `values()` で回す（倒された敵がキーに残った辞書を `for k in 辞書` で回すと、消えた敵のメモリが新しい敵に使い回されていたときに終わらなくなり、レベルアップ時のオートセーブでゲームが固まっていた）
   - ロードしたゲームでもう一度ゲームオーバーになると、歴代記録の**そのゲームの記録を新しい結果で上書きする**（1ゲーム1件。何回リスタートしても同じ。前より悪い結果でも最新の結果に置き換わり、順位も並べ直す。ゲームごとの番号 `run_id` をオートセーブに入れて見分ける。`records.gd` の `"run"`）。この機能より前の記録には番号がないので、前のバージョンで付いた記録は上書きされず、リスタート後に1件増える（そのあとのリスタートでは、その1件が上書きされる）
   - ゲームオーバー画面の「戦績まとめ」の下にある **「歴代記録」ボタン** で、これまでの記録のTOP20（順位・レベル・防衛時間・日付 yyyy/mm/dd）が見られる。下にスクロールできる。順位はレベルが高い順、同じなら防衛時間が長い順（それも同じなら先に出した記録が上）。21番目以下は消える
   - 記録にはゲームのバージョンが付き、歴代記録には**今のバージョンの記録だけ**が出る。ほかのバージョンの記録は消さずに残すが表示しない。TOP20もバージョンごと。バージョンが付いていない昔の記録は1.0として扱う（`records.gd` の `load_current`）
   - 記録はゲームオーバーのたびに自動で保存される（`user://records.json`。ゲームを閉じても残る）。今回の記録は色が変わって「NEW」と出る。デバッグ設定から出撃したゲームの記録には「（デバッグ）」と出る
   - 記録を押すと、そのときの「戦績まとめ」が見られる。「歴代記録に戻る（Esc）」で一覧に戻る
   - 「戦績まとめ」では、採掘場があったゲームなら表の下に「採掘場で稼いだ経験値 ○」（採掘場1・2の合計）が出る。歴代記録にも保存される（この機能より前の記録には出ない）
   - ゲームオーバー画面の **「被害結果確認」ボタン**、または歴代記録の下にある同名のボタンで、キャラクター（遊撃・迎撃・近衛・重装）・城・設置物（壁・見張り櫓・かかし・氷像）が、どの敵からどれだけダメージを受けたかが見られる（多い順・割合つき）。どの行も最初はたたんであり、行をクリックすると内訳が開く・閉じる（設置物は「■ 設置物」の下にまとめて出る）
   - 被害状況の画面の上の **「全体」「直近30秒」ボタン** で、ゲーム全体の被害と、直近30秒（ゲーム内の時間で30秒。ゲームオーバー画面ではゲームオーバーまでの30秒）の被害を切り替えられる（最初は全体）。直近30秒も同じ数え方（`main.gd` の `recent_damage()`。1秒ごとにまとめて記録し、30秒より前のぶんは捨てる。`RECENT_WINDOW`）
   - 入るのは実際に減ったHP・耐久（盾で防いだぶん・残りHPを超えたぶんは入らない。壁・氷像は削られた耐久）。敵の弾・砲弾は撃った敵、体当たり・自爆・ビームはその敵のものとして数える。敵の名前はボスなら称号（破城の魔王など）、ほかは「赤い敵」「紫ひし形」「鉄甲兵」など（`enemy.gd` の `KIND_NAME`）。どの敵か分からないダメージは「その他」。デバッグ設定の部隊戦績リセットで0に戻る（直近30秒のぶんも）
   - 被害状況は歴代記録にも保存され、記録の「戦績まとめ」の **「被害状況」ボタン** から見られる（「戦績まとめに戻る（Esc）」で戻る。この機能より前の記録にはボタンが出ない）。直近30秒の被害も保存され、記録の被害状況でも切り替えられる（直近の機能より前の記録には「直近30秒」ボタンが出ない。直近30秒に変える前の記録は、ボタン名は同じだが中身は直近30秒ぶん）
   - しくみ：敵・敵の弾・敵の砲弾がダメージを与えている間だけ `main.gd` の `dmg_from` に敵の名前が入り、受けた側が `note_taken(受けた側, 量)` で `damage_taken` に記録する
5. 城のHPバーの下にある **「戦績まとめ」ボタン** で、戦闘中の部隊・設備ごとの配置数（現在数/上限。城の兵装も含む）・与ダメージ合計・取得した強化数などを確認できる。その下の **「部隊戦績」ボタン**（または **Tab キー**）では、各部隊の個体ごとの与ダメージ・撃破数・回復量・取得Lvと、部隊種ごとの強化レベル合計・特別強化取得数（取得数/全種類数）を確認できる（開いているあいだは一時停止）。被ダメージは表示しない。取得Lvは戦績カードが作られた時点のゲームレベル。兵士・兵装の行をクリックすると、その下に特別強化ごとの与ダメージと回復量の内訳（多い順・割合つき。各強化の初回取得Lvも表示。残りは「通常攻撃・その他」「通常の回復」）が開く。もう一度クリックで閉じる。遊撃のペットは「遊撃ペット」と表示され、合体合体合体ペットがいる場合は専用の「■ 合体合体合体ペット」枠に表示される
   - デバッグ設定メニューの上部操作は2行に分けて表示する。「敵からのダメージ：有効中／無効中」ボタンで、敵から城・部隊・壁・設置兵装へのダメージを切り替えられる（初期状態は有効）。「敵HP：1倍／2倍／3倍／10倍」ボタンで敵のHP倍率を順に切り替えられる（初期状態は1倍）。倍率はレベル・170overtimeのHP倍率に乗算し、切替後に出現する敵へ適用する。この設定はデバッグ設定の保存・読み込みにも含まれる
   - デバッグ設定メニュー（M キーで出るボタンから開く）の **「部隊戦績リセット」ボタン** で、部隊戦績の数字（与ダメージ・撃破数・被ダメージ・回復量・特別強化ごとの内訳など）をすべて0に戻せる。ゲームはそのまま続き、兵士や兵装の行も残る
   - デバッグ設定メニューの強化の一覧では、部隊・兵装の名前の右にある **「全取得」「全解除」ボタン** で、その部隊・兵装（部隊・兵装そのものも含む）の強化をまとめてチェック（レベルは最大）／はずすことができる。「全取得」後に個別にチェックを外した強化は、出撃時にも適用されない
   - オート選択設定の画面では、部隊・兵装ごとに **「最優先」「優先」「ちょっと優先」** のどれか1つにチェックできる。オート選択中は 最優先 → 優先 → ちょっと優先 → それ以外 の順に取り、3つの候補の中に設定してある一番上の段がなければ1回だけリロールする（`auto_pick_ui.gd` の `LEVELS`）。前のバージョンで保存した「最優先」「優先」は、それぞれ「優先」「ちょっと優先」として読み込まれる
   - オート選択設定の画面の **「設定を保存」ボタン** と、デバッグ設定メニューの **「この設定を保存」ボタン** では、名前を付けて保存できる（名前の欄には「設定 月/日 時:分」が入っている。Enter でも保存。同じ名前なら上書き）。保存できるのはそれぞれ最大20個で、20個あるときに保存すると古いものから自動で消える
   - オート選択設定の画面の **「読み込む」ボタン** と、デバッグ設定メニューの **「保存した設定を読み込む」ボタン** を押すと、保存した設定が新しい順に縦に並んで出る。名前を押すとその設定を読み込む（デバッグ設定メニューは、読み込むだけで出撃はまだしない）。右端の **ゴミ箱ボタン** でその保存を消せる。保存がひとつもないときは読み込むボタンは押せない
   - オート選択設定は、ゲームを起動したときに、最後に保存または読み込みした設定を自動で読み込む（それを消していたら一番新しい保存）
   - 保存先は `user://auto_pick_presets.json`（オート選択設定）と `user://debug_presets.json`（デバッグ設定）。前の方式で保存したもの（`user://auto_pick.json` / `user://debug_preset.json`）があれば、最初に一度だけ「以前の保存」という名前で一覧に引き継ぐ
   - オート選択設定・デバッグ設定メニューのチェックボックスは、白い四角にクリックすると黒いチェックが入る見た目（`scripts/check_style.gd`）
   - 与ダメージは、敵の残りHPを超えたぶん（オーバーキル）は数えない
   - 回復量は、実際に回復したぶん（最大HPを超えたぶんは数えない）。修理兵の城の修理・応急手当・大修繕、癒しのさえずり（ペット）、勇猛の突撃（近衛）、吸命の剣と重鎧の自然回復（重装）、鉄壁の陣（迎撃）、城の自然回復・生命の泉・不屈の城（城）が入る。壁を直した回数は「その他」に「直した壁 ○回分」と出る
   - 採掘場1・採掘場2の行の「その他」には、その採掘場で稼いだ経験値が「獲得経験値 ○」と出る（実際に入った経験値。宝石の鉱脈で10になったぶんも入る。トロッコではねた敵1体ごとの経験値+1は採掘場1に入る）。部隊戦績リセットで0に戻る
   - 内訳に出るのは、特別強化で増えた攻撃（爆発・追加の弾・別の技など）のダメージ。威力アップや範囲アップのように、ふつうの攻撃そのものを強くする特別強化は「通常攻撃・その他」に入る。一度に撃つ数が増える・会心や急所でダメージが上がる・威力がたまっていく、のような強化もここに入る（矢倉の執念の矢・会心の一矢、狙撃の急所狙い、重装の連続斬り、迎撃の三叉槍、近衛のとどめの一撃・連続突撃・疾風怒濤など）
   - しくみ：特別強化の攻撃は `main.gd` の `sp_src(戦績カード, 特別強化id)` で作ったカードを src に渡している
6. その下の **「強化状態」ボタン**（または **U キー**）で、取った強化の一覧を確認できる（最大レベルまで取った強化は、Lvの右に★が付く）。一覧は部隊・兵装ごとにまとめてあり、開いたときは全部閉じている。見出しをクリックすると開く・閉じるが切り替わる。項目をクリックすると詳しい内容が見られる（開いているあいだは一時停止）
   - その下の **「完全ランダムオートモード：有効中／無効中」ボタン**は常時表示される。有効中はレベルアップ報酬を通常オートと同じタイミングで自動選択するが、オート選択設定の優先順位・優先候補がない場合のリロールは使わず、候補からランダムに選ぶ。デバッグ用の通常オートと同時に有効な場合も、完全ランダムが優先される。同じ起動中なら「もう一度」とオートセーブ再開後も状態が維持される
7. 画面右下の **「速度」ボタン**（または **F キー**）で、通常速度 ⇔ 2倍速 を切り替えられる

## ルール

- 城のHPは毎秒2だけ自然に回復する（`castle.gd` の `BASE_REGEN`）。もっと回復させるには **修理部隊** が必要（修理玉がためる「回復した量」には自然回復も入る）
- 敵は上や左右から現れて、城を目指して進んでくる
  - 敵が城に触れると、その敵は消えて城がダメージを受ける（経験値は入らない）
  - 敵の弾が城に当たっても城がダメージを受ける
- **遊撃部隊**（強化で加入、最大5人）：フィールドを動き回って敵を倒しに行く
  - 常に自分から一番近い敵を狙って攻撃しに行く
  - 射撃（点）で遠くの敵を、剣（面）で近くの敵をまとめて倒す
  - 攻撃力は5（`soldier_stats.gd`）。通常攻撃は射撃100%・剣320%・突進突き800%。「攻撃力」強化は射撃・剣・突進すべての基準を上げ、剣術は剣の技倍率を上げる
  - 倒されても10秒後に城から復活する
- **迎撃部隊**（強化で加入、最大3人）：盾＋槍で城の近くを守る
  - 盾を向けている前方の狭い範囲からの攻撃は、ダメージが20%になる（大盾1レベルごとに-5%、最大レベル5で完全に防ぐ）
  - 槍はリーチが長いが横幅は狭い（直線上の敵をまとめて貫く）。攻撃力は20（`guard_stats.gd`）。槍術1レベルごとに攻撃力+20%
  - 足が速い（元の2倍）。近くに敵がいない待機中は、城へ飛んでくる敵の弾の通り道に立って、盾で正面から受け止める
- **近衛部隊**（強化で加入、最大3人）：フィールドの一番下にいる敵（城に一番近い高さの敵）を最優先で狙う
  - 敵との距離285以内で突進を開始する。突進速度は1430、基本距離は338（変更前の1.3倍）。一直線に通り道の敵をまとめて貫き、突進中は無敵
  - 攻撃力は120（`knight_stats.gd`）。突進は攻撃力の100%。剛突と、とどめの一撃の撃破バフで上がる。隠密兵（エリート隠密兵も）は、突進が当たったらダメージなしでその場で倒れる
- **修理部隊**（強化で加入、最大3人）：城のまわりを歩きながら修理して、1人につき城のHPを毎秒1回復する（敵からは狙われない）
- **狙撃部隊**（強化で加入、最大3人）：迎撃部隊の後ろ（城の屋根の上あたり）に立ち、弓で遠くを狙い撃つ（矢はとても速く、最初から敵を2体貫通する）。最大HP 60。矢の攻撃力は40・2秒ごと（`sniper_stats.gd`）。
- 攻撃力を基準にする攻撃は「攻撃力×技倍率」で計算する。技倍率はコードで `2.0` と書かれていれば攻撃力の200%。通常強化の攻撃力+20%/Lvは攻撃力を `(1 + 0.2 × Lv)` 倍する。攻撃速度+20%/Lvは攻撃頻度に `(1 + 0.2 × Lv)` を掛け、発射・攻撃間隔は基準間隔をその倍率で割る（Lv5で攻撃速度200%、間隔は基準の1/2）。敵HP依存・割合依存など独自計算の攻撃はその式を技倍率に重ねる。

- **重装部隊**（強化で加入、最大2体）：足は遅いが攻撃力が高い（最大HP270・自然回復 毎秒4）
  - マップ内を自由に歩き回り、マップの真ん中に一番近い敵を最優先で倒しに行く（敵がいないときはマップの真ん中で待つ）
  - 攻撃は遊撃部隊と同じ扇形の斬撃のみ（範囲は遊撃部隊より大きい）。重装兵の攻撃力は30（`heavy.gd`）。
- **工兵部隊**（強化で加入、最大3人）：ランダムな地点へ移動し、12秒かけて罠を仕掛ける。攻撃力の200%（360）の爆弾と、攻撃力180・範囲内を1秒気絶させる落とし穴を交互に仕掛け続ける
  - 爆弾：近くに敵が来たら1秒後に爆発して範囲ダメージ（160）
  - 落とし穴：近くに敵が来たら1秒後に作動して範囲ダメージ（80）＋範囲内の敵が1秒間動けなくなる
  - 罠はフィールド全体で最大20個。敵からは狙われない
- **築城部隊**（強化で加入、最大3人）：城の上側180度を囲むように、20秒ごとに壁を1枚（約12度）建てる
  - 15枚建てば半円が完成。壊れた場所には建て直しに行く
  - 壁1枚の耐久は10（大きな壁で幅が広いと、幅に合わせて増える：16度で13、20度で17、24度で20）。敵の弾は1発で耐久1、敵が体当たりすると耐久5削れる（ダメージの大きさには関係なし）。ぶつかった敵はダメージを受けず（`enemy.gd` の `WALL_HIT_RATIO` は0）、上側へ大きく弾き飛ばされて1秒気絶する（自爆兵だけはその場で爆発して消える）
- **採掘場**（城の兵装。強化で設置）：城の右側・壁の外（城から右へ300の所）に置かれる（特別強化「第二採掘場」で、反対の左側にももう1つ）。敵からは狙われない
  - 待機中で手の空いた兵士（遊撃・迎撃・狙撃・近衛・重装・工兵・築城・修理。修理兵は城のHPが満タンのときだけ行き、城がダメージを受けたらすぐ修理に戻る。ペットは行かない）が1か所に1人だけ掘りに行く。採掘場から一番近い兵士ではなく、先に手が空いた兵士が行く（空いている採掘場が2つあれば近い方へ）
  - ほかにやることがある兵士は行かない（迎撃兵が城へ飛んでくる弾を受け止める・築城兵が壁や見張り櫓を建てる／櫓に乗る・工兵が罠を仕掛ける、などが優先）。敵が来るなどいつもの動きが始まったら、すぐに採掘をやめて戦いに戻る
  - 掘っている間だけ時間が進み、10秒ごとに経験値を1獲得する（「+1 EXP」と出る。通常のレベル経験値倍率はかからないが、Lv50以上の50overtime倍率はかかる）。採掘場の上の黄色い横向きメーターが、採掘完了までの進み具合。掘るのを中断しても、たまった分はそのまま残り、次に掘りに来たら続きから進む）
  - 部隊戦績には「採掘場1」（右）・「採掘場2」（左、第二採掘場）のカードがあり、特別強化のダメージ（岩のかけら・もぐら・発破用の爆弾・暴走トロッコ）と城の補修石の回復量が記録される（暴走トロッコは採掘場1に入る）
  - 採掘場の特別強化の攻撃は、採掘場に威力がないので「基本の威力×（1＋経過秒÷120）」で時間とともに強くなる
- **ノックバックのクールタイム**：どんな攻撃でも、同じ敵が押されるのは1秒に1回だけ（`enemy.gd` の `KB_COOLDOWN`）。押されたあと1秒は、ほかの攻撃が当たっても押されない（壁にぶつかったときの弾かれは別）
- 射撃（弾・矢・火矢など）でも敵は少し押し戻される（下側の城の方へは押されない）。爆発・斬撃・突進・転がる物などでは大きく吹き飛ぶ
- どんな攻撃のノックバックでも、敵が城に近づく向きには押されない（城へ向かう分の力は消えて、横や奥へだけ押される）
- 動かない敵（砲台要塞・迫撃砲・誘導砲兵）と鉄甲兵は、どんな攻撃でもノックバックしない（鉄甲兵は壁にぶつかっても弾き飛ばされず、気絶だけする。近衛の連行突撃でも運ばれない）
- 敵を倒すと経験値が入り（敵・ボス・黄金の壁・城の蓄えは、Lv1〜9で1.4倍。レベルが10上がるごとに0.08ずつ下がり、Lv50で1.0倍になる（それ以上は下がらない）：Lv10で×1.32、Lv30で×1.16、Lv50以降は×1.0。`main.gd` の `XP_GAIN` / `XP_LEVEL_DROP` / `XP_LEVEL_MIN`）。さらに**50overtime**として、Lv50以上では獲得経験値がLv50で+0.72%、以降1レベルごとにさらに+0.72%ずつ増える（Lv50で×1.0072、Lv100で×1.3672、Lv120で×1.5112。上限なし）。この倍率は敵・ボス・黄金の壁・城の蓄え・採掘場・トロッコのすべてに適用される。採掘場・トロッコには通常のレベル経験値倍率はかからない。経験値の端数はためておいて1たまったら入る（`XP_OVERTIME_FROM` / `XP_OVERTIME_PER_LV`）。レベルアップで強化を3択から1つ選べる

### 敵
- 敵とボスのHP倍率は、出現時のレベルで決まる。Lv1〜50は×1から×4まで直線で増える。Lv50〜160は下記の目安を通る区分線形で増える。Lv160以降は最後の傾き（1Lvごとに+6）で直線的に増える。目安はLv1×1、Lv40×3.39、Lv50×4、Lv60×9.33、Lv70×14.67、Lv80×20、Lv90×37.5、Lv100×55、Lv110×92.5、Lv120×130、Lv130×165、Lv140×200、Lv150×260、Lv160×320。時間経過による通常HP増加、ボス専用の時間カーブ、ボス出現回数・ボスレベルによる追加倍率はない（`main.gd` の `level_hp_mult()`）。
- **170overtime**（Lv170以降の難易度上昇）：Lv170到達時に「ゲームクリア！」「ここからは敵のパターンは変わらず、敵の強さが超上がります。」画面を表示し、閉じると通常のLv170の強化報酬へ進む。敵のHPはレベル別基本倍率に加えて**乗算で1.5倍**。さらに**Lv170になった時刻から**、1分たつごとにHP倍率へ+10%ずつ加算する（足し算・上限なし：1分で+10%、10分で+100%、60分で+600%。1.5倍開始倍率に乗算）。敵の移動速度も**1 + 城Lv/1000倍**になり、Lv170で1.17倍。HP・移動速度の補正はふつうの敵・鉄甲兵・迫撃砲部隊・手下・すべてのボス・黒衣の大司教に適用する。HPは既に出ている敵にはさかのぼって適用されないが、移動速度倍率は現在の城Lvに応じて既存の敵にも適用される。壁が受ける敵の耐久ダメージには、Lv170以上でレベルの百の位（Lv170〜199は+1）を加える。城が受けるダメージへの固定加算はない。分裂の魔獣の分かれた体と分裂体は、親が出たときのHP倍率を引き継ぐ。始まった時刻はオートセーブに入る。Lv170以降も敵の攻撃力はレベルで増えない。デバッグ設定でLv170以上から出撃したら、出撃した時刻から始まる（`main.gd` の `OVERTIME_FROM_LV` / `OVERTIME_HP_PER_MIN` / `overtime_start`）
- 敵の与ダメージ（味方へも城へも）は、レベルが上がっても変わらない（ボスも含む。ボスの弾・ビームの威力も、何体目のボスかに関係なく一定。前にあった「レベル100ごとに+1」と「ボスの弾が出現回数ごとに+30%」はなくした）

- **赤（grunt）**：まっすぐ城へ向かう基本の敵
- **紫ひし形（archer）**：城だけを撃ってくる。城へ近づいてきて、出てきてから8秒たったら（どこにいても）撃ち始める。そのあとはずっと撃ち続ける（射程は無限。兵士は狙わない・挑発にもかからない）。迎撃部隊は紫ひし形には反応しない（盾も向けず狙いもしない。撃ってきた弾には盾を向ける。ほかの敵を突いたときに一緒に当たるのはそのまま）（25秒〜）
- **オレンジ（runner）**：小さくて速い（45秒〜）
- **大きい暗赤（brute）**：硬くて重い。城に触れると大ダメージ（80秒〜）
- **青緑のとがった敵（hunter／刺客）**：城は無視して兵士（遊撃・迎撃）だけを狙う。壁もすり抜ける（75秒〜）
- **黄緑の塊（splitter／分裂体）**：倒すと小さな分裂体3体に分かれる（60秒〜）
- **ピンクの十字（healer／治癒師）**：後方にとどまり、3秒ごとに周りの敵を回復する。少し硬い（HP75）（100秒〜）
- **黒っぽい赤（bomber／自爆兵）**：足が速い。兵士・壁・城にぶつかると爆発（壁の耐久を15削る）（120秒〜）
- **半透明の灰色（stealth／隠密兵）**：画面の右下・左下の隅から現れて城を狙う。壁のない横から攻めてくる。HPは低めだがとても速い（90秒〜）
- **金のふちの濃い紫（elite_stealth／エリート隠密兵）**：隠密兵と同じく右下・左下の隅から現れて城を狙う、半透明の敵。隠密兵の半分の速さ（80）で、HPは3倍（45）。少し大きい。攻撃の強さ・近衛の突進で一撃で倒れるのは隠密兵と同じ。経験値6（隠密兵の3倍）。4分〜、隠密兵とは別に出る（出やすさ 0.5＋秒/600。20分で隠密兵の約1/3）
- **砲身つきの土台（mortar／迫撃砲）**：マップの端（上端・左右）に陣取って動かず、壁を飛び越える山なりの砲弾で城を撃ってくる。着弾地点には赤い印が出る（180秒〜、同時に出る数に上限あり）
- **赤いトゲトゲの玉（ringer／弾幕兵）**：5秒ごとに全方位へ赤い弾を10発撃ちながら、城へ向かってくる（150秒〜）
- **ミサイル発射台（seeker／誘導砲兵）**：マップの端に陣取って動かず、遊撃・近衛・重装のキャラクターへ（迎撃と、見張り櫓・かかしなどの設置物は狙わない）、しつこく曲がって追いかけてくる誘導弾を2〜3秒ごとに撃つ（200秒〜、同時に出る数に上限あり）
- **鋼色の鎧（ironclad／鉄甲兵）**：暗い青鋼色の大きな体に、明るい縁どりと正面の盾板。とても遅いがとても硬い（HP500）。ノックバックが効かない。城に触れるとダメージ大（20）（5分ごとに10体ずつまとめて上端に横一列で出る。ただし黒衣の大司教が来る10分・20分・30分…の回は出ず、5分・15分・25分…だけ。ふつうの出現には混ざらず、敵の数の上限も無視する。`main.gd` の `IRONCLAD_EVERY` / `IRONCLAD_COUNT`）。**Lv100を超えてからは**、それとは別に1分ごとに3体ずつ上端に出てくる（アナウンスなし。Lv100を超えた時から数える。`IRONCLAD_LATE_EVERY` / `IRONCLAD_LATE_COUNT`）
- 30秒ごとに横一列の大群が来る（数は 8 + 経過秒数÷25。ただしフィールドの敵が300体を超えないぶんだけ。すでに300体いるときは出ない。`main.gd` の `WAVE_EVERY` / `WAVE_FIELD_CAP`）
- Lv5・15・25…になると、迫撃砲部隊（迫撃砲8体）がマップの端に一気に現れる
- ボス・迫撃砲部隊のような「Lv刻みの敵」は、どのレベルの分まで出したかを覚えている（`main.gd` の `milestone_level`。オートセーブにも入る）。デバッグ設定でちょうどLv10・15・20…から始めたときは、そのレベルの分がすぐに出る（それより前のレベルの分は出さない）。そのあとのレベルアップでは、いつもどおりLv刻みで出る。オートセーブから再開したときも、そのレベルの分がまだ出ていなければ出す
- 画面右上に、いま侵攻中の敵の数が出る

### ボス（Lv10ごと）

Lv10・20・30…になると、画面上からボスが現れる（画面上部にHPバーと名前が出る）。3種類のボスが順番に来る（破城の魔王 → 砲台要塞 → 分裂の魔獣 → 破城の魔王…）。
**Lv130からはボスが2体同時に出る**（そのかわり1体ずつのHPは半分）。順番の続きの2体が組になる：Lv130 魔王＆要塞 → Lv140 分裂＆魔王 → Lv150 要塞＆分裂 → …。HPバーは上下に分かれて、それぞれのボスの名前と残りHPが出る（倒したほうのバーは消える）。全部倒すと撃破（`main.gd` の `DOUBLE_BOSS_FROM`）。
**Lv160からはボスが3体同時に出る**（1体ずつのHPは1/3）。順番の続きの3体なので、毎回3種類が1体ずつそろう（左・真ん中・右に並ぶ。`TRIPLE_BOSS_FROM`）。
ボスの基本HPにも上記と同じ出現時レベル倍率をかける。Lv130からは2体同時、Lv160からは3体同時に出るため、同時出現数で1体あたりの倍率を割る。ボスの基本HPは1.1倍（元の基礎値に対する倍率）に変更済み（破城の魔王847、砲台要塞453.75、分裂の魔獣は初期の体169.4・分裂後を含む合計847、黒衣の大司教3300）。分裂の魔獣は分裂するたびにHPが半分になる。ボスの出現回数によるHP増加や、ボス専用のレベル・時間倍率はない。
- キャラクターを狙った誘導弾（誘導砲兵・砲台要塞の誘導弾）は城には当たらず、すり抜ける（壁には当たる）。誘導弾の大きさはふつうの弾の約2倍（半径16）。城ロボの誘導ミサイルも元の2倍の大きさ（当たり判定の半径18）
- 5分までは、城とキャラクター（遊撃・迎撃・近衛・重装）が受けるダメージがすべて半分（ふつうの敵もボスも。壁・見張り櫓などの設置物は半分にならない。`castle.gd` の `EARLY_HALF_UNTIL`、`main.gd` の `early_damage_mult`）

**破城の魔王**（Lv10・40・70…）
- 約1.7秒ごと（5秒の3倍の頻度）に全方位へ弾を撃ち、8秒ごとに手下を5体呼ぶ
- 壁に触れると壁の耐久を7減らす。ボス自身はダメージを受けず、ノックバックもしない（消えずに何度もぶつかってくる）
- 城に着くと、消えずに2秒ごとに大ダメージを与え続ける

**砲台要塞**（Lv20・50・80…）
- 画面上部に陣取って動かない（ノックバックも効かない）。HPは破城の魔王より低い。そのかわり3つの攻撃を「ぐるぐる射撃 → 誘導弾 → ぐるぐる射撃 → 誘導弾 → ビーム」の順でくり返す（`enemy.gd` の `FORTRESS_SEQ`）
  1. **全方位ぐるぐる射撃**：10本の腕のうずまき弾幕がぐるっと2.5周（約2.5秒。弾は味方・壁・城のどれかに1発当たったら消える。城に当たったときのダメージは2割。`enemy.gd` の `SPIRAL_SHOTS`）
  2. **誘導弾20発**：一番近いキャラクターを追いかける弾（約1.6秒で20発。`enemy.gd` の `HOMING_SHOTS`）
  3. **城狙いビーム**：1秒前に予告線が出てから、城までの一直線上にある味方・壁・城をまとめて撃ち抜く。城には最大HPの10%のダメージ（`enemy.gd` の `BEAM_CASTLE_RATIO`）

**分裂の魔獣**（Lv30・60・90…）
- 緑のスライムのボス。全方位へ弾を撃ちながら城へ進んでくる（約1.2秒ごと。3.5秒の3倍の頻度。最初の体の基本HPは169.4。分かれた体ぜんぶの合計HP（847）は、破城の魔王と同じ）
- 倒されると2体に分裂し、それも倒されるとさらに2体に…と最大4回分裂する（最後は16体）
- 分裂するたびにHPは半分、体は小さく、足は速く、弾は少なくなる（弾1発の威力・体当たりのダメージ・城を殴るダメージ（20）は、分かれても同じ）
- HPバーには、分かれた体ぜんぶのHPの合計と、残りの体の数が出る。全部倒すと撃破

**黒衣の大司教**（レベルとは別に、10分・20分・30分…ごとに出現）
- 黒いローブに紫の魔法陣をまとったボス。画面の上のほうをゆっくり左右に漂い、城へは近づかない。ノックバックは効かない
- 大司教が生きているあいだは、倒されたボス以外の敵が**1回だけ、その場でHP30%で復活する**（復活した敵は紫のもやをまとう。復活したときは撃破数・経験値に入らない）
- 大司教が生きているあいだは、**10秒ごとに「号令」**：大司教自身が、上以外（右から下を通って左まで）のランダムな方向へ大きな紫の弾を1秒に30発で高速連射する。撃つ数は、撃ち始めたときの侵攻中の敵の数（画面右上の数）の2倍。連射が終わってから10秒で次の号令（`enemy.gd` の `BISHOP_SHOTS_PER_ENEMY` / `BISHOP_FIRE_RATE`）。1発の威力は大司教の攻撃力の1.5倍。ほかの敵はもう撃たない。この弾は**貫通無限**（兵士を突き抜け、壁も素通りする。城に当たったら消え、城にもそのままのダメージ（減らない））
- HPは基本3000 × 敵共通のレベル倍率 × 170overtime倍率。前の大司教がまだ残っていたら、次は出ない（`main.gd` の `BISHOP_EVERY`）
- **倒すと特別強化の3択が1回出る**（画面の上は「★ 特別強化 ★  大司教撃破」。レベルアップの3択と同じ順番待ちに入り、同時にレベルが上がったらそのあとに出る。オート選択・リロール・オートセーブ（選ぶ前にセーブしてロードしても同じ3択）もレベルアップと同じ。取れる特別強化が残っていなければ通常の強化。`main.gd` の `BISHOP_BONUS_LEVEL`）

**ボスが撃つ弾は2回当たるまで消えない**：兵士・迎撃兵・壁のどれかに1回当たっても突き抜けて飛び続け、2回目に当たったところで消える（例：壁に当たって突き抜け、その先の迎撃兵に当たって消える）。壁に当たると壁の耐久は1削れる。城に当たったらすぐ消える。
どのボス（黒衣の大司教・分裂の魔獣の分かれた体も）も、攻撃によるノックバック・押し出し・吸い寄せ（竜巻・吸引砲）・気絶（凍結も）が効かない（氷結の結界や居座り岩などで足が遅くなるのは効く。壁にぶつかったときに弾かれるのはそのまま）。治癒師の回復もほとんど効かない。ボスのHP倍率は出現時のレベルと170overtime経過時間で決まる。倒すと経験値が多い。
ボスと鉄甲兵はほかの敵とぶつからない（重なってすり抜ける。ボスどうしもぶつからない）。分裂の魔獣の体どうし、鉄甲兵どうしだけはぶつかって押し合う（`enemy.gd` の `_separate`）。
ボスの移動速度はHPで変わる：HP満タンのときは基本の0.1倍で、HPが減るほど速くなり、残り25%で基本の速さ（それ以上は速くならない。`enemy.gd` の `BOSS_SLOW_MIN` / `BOSS_FULL_SPEED_AT`）。砲台要塞は動かないかわりに、攻撃速度に同じ倍率をかける。分裂の魔獣は、1体ずつのHPではなく**分かれた体ぜんぶの合計HPの割合**で決まる（全部の体が同じ倍率。まだ分かれていない分も残りに入れるので、分裂してもリセットされない。最初の体が満タンで0.1倍 → 全体の残り25%で1倍。もとの足の速さ「分裂するたびに1.18倍」はそのまま。`enemy.gd` の `_split_total_ratio`）

#### 城（本体）の特別強化（城はいつもいるので、いつでも候補に出る）

| 城レーザー | 40秒ごとに、城から、正面（真上）から始まってぐるっと1周し正面で終わるレーザーでマップ全体を薙ぎ払う（威力はレベル×15） |
| 城の火炎くしゃみ | 15秒ごとに、城の中心（城ロボ起動中は城ロボの中心）から、マップの真ん中を目がけて2秒間の火炎放射（長さ560の扇形・0.1秒ごとにレベル×2.25のダメージ。吹き飛ばしはしない）。城ロボがファイナルモードのときは、右上・右下・左上・左下の4方向へ吹く。真・ファイナルモードの間は、城レーザーと同じように火炎を出し続ける（ダメージは今までどおり「城の火炎くしゃみ」として記録） |
| 城の蓄え | 城が受けたダメージ10ごとに経験値+1（背水の修繕で減る分は入らない） |
| 城ロボ起動 | 城からロボットが出撃して25秒間暴れまわり、戻ってから25秒後にまた出撃する（フライト・ファイナルモードも同じ。最初の出撃は取ってから10秒後。いつもゆっくり歩き、全方位にぐるぐる射撃（基本威力3）、2秒ごとに近くの敵をパンチ（基本威力40）。城は動かない。城ロボ本体の攻撃は「基本ダメージ×Lv×（1＋設置兵装数×0.25）」で計算する（各兵装1基ごとに+0.25。矢倉4・大砲3・投石器3・バリスタ4・連射砲2の全16基でLv×5.0）。特別強化の候補weightは、矢倉・大砲・投石器・バリスタ・連射砲の強化レベル合計に応じて上がり、合計16レベルで最大4.0になる（`upgrades.gd` の `ROBOT_WEIGHT_PER_LEVEL`） |

| 城ロボ 真・ファイナルモード | ファイナルモードを取っていると候補に出る。ただし城の火炎くしゃみと城レーザーを両方取っていないと選べない（候補には灰色で出る。説明文にも「「城・城の火炎くしゃみ」と「城・城レーザー」を取得している場合のみ取得できる」と書いてある。`upgrades.gd` の `req_owned`）。城ロボがもう城に戻らず、ずっと出撃したままになる。金色の「真・ファイナルモード」（25秒・画面の真ん中）→ 通常の城ロボが真ん中に出撃（20秒）→ 足を止めて体を震わせ、1秒ごとに1本ずつ白い光が体からマップの端まで伸びる（5秒）→ 真・ファイナルモード … をくり返す。真・ファイナルモードはファイナルモードの攻撃（ビーム10本・誘導ミサイル・上下2本の城レーザー・4方向の火炎くしゃみ）に加えて、出撃から10秒後と20秒後に両目から太い虹色レーザーを、体力が一番多い敵へ4秒間ずつ撃つ（マップの端まで届き、途中の敵にも当たる。片目ずつ0.1秒ごとに基本威力10×Lv×（1＋設置兵装数×0.25）のダメージ）。城レーザーを持っていると、真・ファイナルモードの間は上下2本の城レーザーが撃ちっぱなしでずっと回り続ける（このときの城レーザーのダメージは1/4＝レベル×3.75。`castle.gd` の `LASER_TRUE_MULT`。通常の城ロボのときは、出撃から7秒後に1本で、ダメージはふつうどおり。光をためる間もふつうどおり）。真・ファイナルモードの間の城ロボの攻撃（ビーム・誘導ミサイル・虹色レーザー）は、すべて城ロボの内訳の「真・ファイナルモード」として記録する（城レーザー・炎くしゃみは城の攻撃として今までどおり記録）。くり返しの途中で通常の城ロボに戻っている間の射撃・パンチは、「通常攻撃・その他」ではなく「真・ファイナルモード・クールタイムロボ」として記録する |

部隊の強化はその部隊の全員に効く（あとから増員された兵士にも反映される）。
迎撃・築城の強化は、その部隊が加わってから候補に出るようになる。
新しい強化を追加するときは `upgrades.gd` の `LIST` に1行追加し、`apply()` に効果を書く。

## 調整しやすい値

- 難易度：`main.gd` の `SPAWN_BASE` / `SPAWN_GROWTH` / `SPAWN_MAX`（出現ペース。今は5分で上限）、`MAX_ENEMIES`（フィールドの敵がこの数以上いるあいだは、ふだんの出現が止まる。今は300体。30秒ごとの大群もフィールド全体で300体まで）、`level_hp_mult()`（敵・ボス共通のレベル別HP倍率）、`OVERTIME_FROM_LV` / `OVERTIME_HP_PER_MIN`（170overtimeのHP増加）
- 必要経験値：`main.gd` の `xp_needed()`（`(4 + 3×Lv + Lv²÷7) ÷ 1.44`）
- 城のHP：`castle.gd` の `max_hp`
- 遊撃部隊の初期ステータス：`soldier_stats.gd`
- 迎撃部隊の初期ステータス：`guard_stats.gd`
- 壁の建築時間・防げる回数・幅：`walls.gd` の `build_time` / `wall_max_hp` / `wall_width`
- 最初の兵士数：`main.gd` の `_ready()` で `add_soldier()` を呼んでいる回数
- 敵のステータス：`enemy.gd` の `setup()`
