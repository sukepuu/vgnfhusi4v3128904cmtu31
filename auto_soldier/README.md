# Auto Soldier（Godot 4.7 / 2D）

フィールドの一番下にある城を、自動で戦う部隊（遊撃・迎撃・重装・築城・工兵）と城の迎撃システムで守るゲーム。
プレイヤーが操作するのは、レベルアップ時の強化を3択から選ぶことだけ。

## 遊び方

1. Godot 4.7 で `auto_soldier/project.godot` を開く
2. F5（または右上の再生ボタン）で実行
3. レベルアップしたら強化を **クリック** か **1〜3キー** で選ぶ
4. 城のHPが0になるとゲームオーバー。**R キー** かボタンでリトライ
5. 城のHPバーの下にある **「部隊戦績」ボタン**（または **Tab キー**）で、各部隊の個体ごとの与ダメージ・撃破数・被ダメージを確認できる（開いているあいだは一時停止）
6. その下の **「オート選択」ボタン**（または **A キー**）で有効にすると、レベルアップの強化をランダムで自動的に選ぶ（ゲームは止まらない）

## ルール

- 城のHPは毎秒2ずつ自然回復する（「修理工」でさらに増える）
- 敵は上や左右から現れて、城を目指して進んでくる
  - 敵が城に触れると、その敵は消えて城がダメージを受ける（経験値は入らない）
  - 敵の弾が城に当たっても城がダメージを受ける
- **遊撃部隊**（最初は2人）：フィールドを動き回って敵を倒しに行く
  - 常に自分から一番近い敵を狙って攻撃しに行く
  - 射撃（点）で遠くの敵を、剣（面）で近くの敵をまとめて倒す
  - 倒されても10秒後に城から復活する
- **迎撃部隊**（強化で加入、最大3人）：盾＋槍で城の近くを守る
  - 盾を向けている前方の狭い範囲からの攻撃は完全に無効
  - 槍はリーチが長いが横幅は狭い（直線上の敵をまとめて貫く）
- **重装部隊**（強化で加入、最大1体）：足は遅いが耐久力と攻撃力が高い
  - 壁の中央（城の真上）の外側に陣取り、近づく敵を迎え撃ちに行く（持ち場から離れすぎない）
  - 攻撃は遊撃部隊と同じ扇形の斬撃のみ（範囲・威力は遊撃部隊より大きい）
- **工兵部隊**（強化で加入、最大2人）：ランダムな地点へ移動し、5秒かけて罠を仕掛ける。爆弾と落とし穴を交互に仕掛け続ける
  - 爆弾：近くに敵が来たら1秒後に爆発して範囲ダメージ（200）
  - 落とし穴：近くに敵が来たら1秒後に作動して範囲ダメージ（100）＋範囲内の敵が10秒間動けなくなる
  - 罠はフィールド全体で最大20個。敵からは狙われない
- **築城部隊**（強化で加入、最大3人）：城の上側180度を囲むように、20秒ごとに壁を1枚（約12度）建てる
  - 15枚建てば半円が完成。壊れた場所には建て直しに行く
  - 壁1枚で、敵の体当たりや敵の弾を10発まで防ぐ（ダメージの大きさに関係なく1回は1発）。防いだ敵は消滅する
- 敵を倒すと経験値が入り、レベルアップで強化を3択から1つ選べる

### 敵

- **赤（grunt）**：まっすぐ城へ向かう基本の敵
- **紫ひし形（archer）**：離れた所から城や兵士を撃ってくる（25秒〜）
- **オレンジ（runner）**：小さくて速い（45秒〜）
- **大きい暗赤（brute）**：硬くて重い。城に触れると大ダメージ（80秒〜）
- **青緑のとがった敵（hunter／刺客）**：城は無視して兵士（遊撃・迎撃）だけを狙う。壁もすり抜ける（75秒〜）
- **黄緑の塊（splitter／分裂体）**：倒すと小さな分裂体3体に分かれる（60秒〜）
- **ピンクの十字（healer／治癒師）**：後方にとどまり、3秒ごとに周りの敵を回復する（100秒〜）
- **黒っぽい赤（bomber／自爆兵）**：足が速い。兵士・壁・城にぶつかると爆発（壁は3発分削る）（120秒〜）
- 50秒ごとに横一列の大群が来る

### ボス（Lv10ごと）

Lv10・20・30…になると、画面上からボスが現れる（画面上部にHPバーが出る）。
- 5秒ごとに全方位へ弾を撃ち、12秒ごとに手下を5体呼ぶ
- 壁にぶつかっても消えず、壁を1枚まるごと壊して進む
- 城に着くと、消えずに2秒ごとに大ダメージを与え続ける
- ノックバックや気絶はほとんど効かない。出るたびに強くなる。倒すと経験値が多い

### 強化一覧（`scripts/upgrades.gd`）

| 種類 | 強化 |
| --- | --- |
| 【遊撃】 | 遊撃兵を増員（最大5人）、射撃数+1、速射、強化弾、貫通弾、剣術、大振り、回転斬り、突進突き、ペットの仲間（取るたびに全遊撃兵に1匹ずつ）、鍛錬（HP）、俊足 |
| 【迎撃】 | 迎撃部隊（加入・増員）、大盾（盾の範囲）、機動訓練（移動速度）、長槍（リーチ）、槍術（攻撃力） |
| 【重装】 | 重装部隊（加入）、剛剣（威力）、連撃（間隔）、大薙ぎ（範囲）、重鎧（HP・回復）、軽量化（速度・行動範囲）、旋風斬り（360度） |
| 【工兵】 | 工兵部隊（加入・増員）、高性能火薬（罠の威力）、手際（設置時間・速度）、広域罠（範囲）、深い落とし穴（足止め時間） |
| 【築城】 | 築城部隊（加入・増員）、突貫工事（建築時間）、石壁強化（壁が防げる回数）、大きな壁（壁の幅） |
| 【城】 | 矢倉（自動で矢を撃つ）、大砲（密集地へ範囲攻撃、最大3門）、投石器（大砲より広範囲・間隔長め、最大3台）、バリスタ（間隔長め・高威力・射程無限・貫通無限、最大3基、増やすと威力も上がる）、砲術（大砲・投石器の威力）、氷結の結界（近くの敵を遅くする）、城壁補強（HP）、修理工（HP回復） |

### ★特別強化（Lv7ごと）

Lv7・14・21…に上がったときは、3択が「★特別強化★」になる（持っている部隊・設備のものだけが候補に出る。候補がなければ通常の強化）。
特別強化にレベルはなく、どれも1回取れば完成。

| 種類 | ★その1 | ★その2 | ★その3 |
| --- | --- | --- | --- |
| 遊撃 | 炸裂弾：弾が当たると小爆発 | 一斉射撃：6秒ごとに全方位へ18発 | 剣気：斬撃と一緒に貫通する衝撃波が飛ぶ |
| 迎撃 | 盾撃：盾で防ぐたびに衝撃波 | 三叉槍：槍が3方向に出る | 挑発：近くの敵が迎撃兵を狙う |
| 重装 | 連続斬り：斬撃が3回連続 | 地割れ：5秒ごとに周りへ大ダメージ＋気絶 | 吸命の剣：与ダメージの10%回復 |
| 築城 | 砲台壁：壁から弾を撃つ | 自己修復：壁が3秒ごとに回復 | 爆裂壁：防ぐたびにその場で爆発 |
| 工兵 | 子爆弾：爆発後に小爆弾が6個 | 毒沼：落とし穴の跡が毒の沼に | 二重設置：爆弾と落とし穴を同時に設置 |
| 矢倉 | 連射：一度に3本 | 徹甲矢：3体貫通＋威力+60% | 会心の一矢：25%でダメージ3倍＋射程+40% |
| 大砲 | 散弾砲：周りにも4発落ちる | 焼夷弾：着弾地点が6秒燃える | 速射砲：発射間隔-40% |
| 投石器 | 大岩：範囲+40%・威力+80% | 分裂岩：着弾後に6個の岩が落ちる | 岩雨：ランダムな敵2体にも岩が落ちる |
| バリスタ | 連装：一度に3発 | 爆裂ボルト：貫いた敵ごとに小爆発 | 大型弩：当たり判定拡大＋威力+50% |
| 氷結の結界 | 絶対零度：8秒ごとに結界内の敵を凍らせる | 氷柱：1.5秒ごとに氷柱が2本降る | 吹雪：結界内の敵に継続ダメージ |

部隊の強化はその部隊の全員に効く（あとから増員された兵士にも反映される）。
迎撃・築城の強化は、その部隊が加わってから候補に出るようになる。
新しい強化を追加するときは `upgrades.gd` の `LIST` に1行追加し、`apply()` に効果を書く。

## ファイル構成

```
auto_soldier/
├── project.godot
├── scenes/main.tscn        … ルートのシーン（中身はすべてスクリプトで生成）
└── scripts/
    ├── main.gd             … フィールド・敵の出現・経験値/レベル管理
    ├── castle.gd           … 城（HP・矢倉・大砲・投石器・バリスタ・氷結の結界）
    ├── walls.gd            … 城を囲む半円の壁（当たり判定・建てる場所の決定）
    ├── builder.gd          … 築城部隊
    ├── engineer.gd         … 工兵部隊
    ├── engineer_stats.gd   … 工兵部隊と罠のステータス
    ├── trap.gd             … 工兵が仕掛ける罠（爆弾・落とし穴）
    ├── soldier.gd          … 遊撃部隊（遊撃AI・射撃・剣・突進・復活）
    ├── soldier_stats.gd    … 遊撃部隊で共有するステータス
    ├── guard.gd            … 迎撃部隊（盾・槍）
    ├── guard_stats.gd      … 迎撃部隊で共有するステータス
    ├── heavy.gd            … 重装部隊（ステータスもこのファイルの先頭）
    ├── enemy.gd            … 敵（近接型・遠距離型）
    ├── bullet.gd           … 弾（味方/敵共通）
    ├── shell.gd            … 大砲の砲弾・投石器の岩
    ├── pet.gd              … ペット
    ├── upgrades.gd         … 強化の定義と効果
    ├── level_up_ui.gd      … 強化3択画面
    ├── hud.gd              … 城のHP・経験値などの表示とゲームオーバー画面
    ├── stats_ui.gd         … 部隊戦績画面
    ├── hazard.gd           … 炎・毒沼など残り続けるダメージ地帯
    ├── blast.gd            … 少し遅れて起きる爆発（子爆弾・分裂岩・氷柱）
    └── slash_effect.gd / damage_text.gd / burst_effect.gd … 演出
```

画像素材は使っておらず、すべて `_draw()` で図形として描いている。
あとからスプライト画像に差し替えたい場合は、各スクリプトの `_draw()` を置き換えればよい。

## 調整しやすい値

- 難易度：`main.gd` の `_update_spawning()`（出現ペース）、`_spawn_enemy()` の HP 倍率
- 必要経験値：`main.gd` の `xp_needed()`
- 城のHP：`castle.gd` の `max_hp`
- 遊撃部隊の初期ステータス：`soldier_stats.gd`
- 迎撃部隊の初期ステータス：`guard_stats.gd`
- 壁の建築時間・防げる回数・幅：`walls.gd` の `build_time` / `wall_max_hp` / `wall_width`
- 最初の兵士数：`main.gd` の `_ready()` で `add_soldier()` を呼んでいる回数
- 敵のステータス：`enemy.gd` の `setup()`
