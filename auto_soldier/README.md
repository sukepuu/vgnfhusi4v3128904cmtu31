# Auto Soldier（Godot 4.7 / 2D）

フィールドの一番下にある城を、自動で戦う遊撃部隊の兵士たちと城の迎撃システムで守るゲーム。
プレイヤーが操作するのは、レベルアップ時の強化を3択から選ぶことだけ。

## 遊び方

1. Godot 4.7 で `auto_soldier/project.godot` を開く
2. F5（または右上の再生ボタン）で実行
3. レベルアップしたら強化を **クリック** か **1〜3キー** で選ぶ
4. 城のHPが0になるとゲームオーバー。**R キー** かボタンでリトライ

## ルール

- 敵は上や左右から現れて、城を目指して進んでくる
  - 敵が城に触れると、その敵は消えて城がダメージを受ける（経験値は入らない）
  - 敵の弾が城に当たっても城がダメージを受ける
- 兵士（最初は2人）は遊撃部隊として自動で敵を倒しに行く
  - 城に近い敵・城を撃っている弓兵を優先して狙う
  - 兵士同士はなるべく別々の敵を狙う
  - 射撃（点）で遠くの敵を、剣（面）で近くの敵をまとめて倒す
  - 倒されても10秒後に城から復活する
- 敵を倒すと経験値が入り、レベルアップで強化を3択から1つ選べる

### 敵

- **赤（grunt）**：まっすぐ城へ向かう基本の敵
- **紫ひし形（archer）**：離れた所から城や兵士を撃ってくる（25秒〜）
- **オレンジ（runner）**：小さくて速い（45秒〜）
- **大きい暗赤（brute）**：硬くて重い。城に触れると大ダメージ（80秒〜）
- 50秒ごとに横一列の大群が来る

### 強化一覧（`scripts/upgrades.gd`）

| 種類 | 強化 |
| --- | --- |
| 【兵士】 | 兵士を増員（最大5人）、射撃数+1、速射、強化弾、貫通弾、剣術、大振り、回転斬り、突進突き、ペットの仲間、鍛錬（HP）、俊足 |
| 【城】 | 矢倉（自動で矢を撃つ）、大砲（密集地へ範囲攻撃）、氷結の結界（近くの敵を遅くする）、城壁補強（HP）、修理工（HP回復） |

兵士の強化は全員に効く（あとから増員された兵士にも反映される）。
新しい強化を追加するときは `upgrades.gd` の `LIST` に1行追加し、`apply()` に効果を書く。

## ファイル構成

```
auto_soldier/
├── project.godot
├── scenes/main.tscn        … ルートのシーン（中身はすべてスクリプトで生成）
└── scripts/
    ├── main.gd             … フィールド・敵の出現・経験値/レベル管理
    ├── castle.gd           … 城（HP・矢倉・大砲・氷結の結界）
    ├── soldier.gd          … 兵士（遊撃AI・射撃・剣・突進・復活）
    ├── soldier_stats.gd    … 兵士全員で共有するステータス
    ├── enemy.gd            … 敵（近接型・遠距離型）
    ├── bullet.gd           … 弾（味方/敵共通）
    ├── shell.gd            … 大砲の砲弾
    ├── pet.gd              … ペット
    ├── upgrades.gd         … 強化の定義と効果
    ├── level_up_ui.gd      … 強化3択画面
    ├── hud.gd              … 城のHP・経験値などの表示とゲームオーバー画面
    └── slash_effect.gd / damage_text.gd / burst_effect.gd … 演出
```

画像素材は使っておらず、すべて `_draw()` で図形として描いている。
あとからスプライト画像に差し替えたい場合は、各スクリプトの `_draw()` を置き換えればよい。

## 調整しやすい値

- 難易度：`main.gd` の `_update_spawning()`（出現ペース）、`_spawn_enemy()` の HP 倍率
- 必要経験値：`main.gd` の `xp_to_next = ...`
- 城のHP：`castle.gd` の `max_hp`
- 兵士の初期ステータス：`soldier_stats.gd`
- 最初の兵士数：`main.gd` の `_ready()` で `add_soldier()` を呼んでいる回数
- 敵のステータス：`enemy.gd` の `setup()`
